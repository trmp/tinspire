tinspire
========

This repository provides syntax definitions for TI-Nspire programs.

* `tinspire.tmLanguage` &ndash; TextMate grammar used by editors like Sublime Text.
* `tinspire.udl.xml` &ndash; Notepad++ user defined language file.

## Using with Notepad++

1. Open **Language &gt; User Defined Language &gt; Define your language...**
2. Click **Import...** and choose `tinspire.udl.xml` from this repository.
3. Restart Notepad++ to enable highlighting for files with the `.txt` extension.
